# 1.88.66 (development)

Title: Door elevations show the front face

- Door sheets: half-lap frame door "Opening Size" views now show the front face. The stiles run full height and the rails show between them; before, the view showed the back, with the rails running full width. This applies to every insert type. Cut sizes, laps and shoulder dimensions are unchanged.
- Door sheets: the member-width (rail/stile width) dimension is removed from all frame-door layouts, and its Dev switch (R-DOOR-RAIL-WIDTH-DIM) is gone.
