## Dev 1.88.75: the Dev tab shows only this version's switches

- The Dev tab now lists switches only for changes made in the installed version. Changes from earlier dev versions are always on and have no switch.
- **All off** now returns only those switches to the previous version's behaviour.
- A version with no switchable changes says so; this one is an example, since its only change is the Dev tab itself.
- Fixes a bug where the 1.88.72 side-pick switch never appeared on the tab ("Console selection" area was missing).
- Drawing output is identical to 1.88.74.
