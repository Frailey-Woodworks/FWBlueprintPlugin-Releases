FW Version Manager 1.1.0

- Cleaner list: Version, Date (shown only where it changes) and a short Note (Stable, or a nickname such as Friday's set). The version Rhino is running is marked.
- Hover over a version to see what changed in it.
- Restart Rhino button: Rhino asks to save first (Cancel stops it), then reopens with your saved file.
- Shorter status and messages.

Update: in FW Version Manager click "Check for a newer FW Version Manager", then restart Rhino.
